---
name: Orvyn guest workspace
description: User requirements for the no-login adaptation of the original Orvyn app.
---

The user wants the same functions and style as their original Orvyn app, but people must be able to use it without logging in and find their work when they return.

**Why:** The user explicitly requested unrestricted no-login use, persistent work, and good usability guided by Nielsen Norman Group’s ten usability heuristics.

**How to apply:** Preserve the supplied source’s visual identity and workflows rather than replacing it with an approximation. Guest persistence is browser-local; disclose same-browser/device limits and clearing-data risks. Do not reintroduce login as a prerequisite. Keep save status, errors, safe deletion, and recovery understandable.
